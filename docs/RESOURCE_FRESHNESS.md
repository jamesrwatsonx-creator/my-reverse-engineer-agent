# Universal resource freshness protocol
Mandatory at each new investigation and selected-tool resume. Updating references is not modifying user forks or downloading executables.
1. Enumerate every unique GitHub primary and related URL in registry/tools.json and prior useful resources. Check non-GitHub sources through official documentation. Scan accessible owner profile for new/recently changed useful repos, skills and APIs via paginated listing/search and relevant nested indexes; document queries, pages, coverage and limits. Register useful candidates, fork parent and original source; never bulk import irrelevant repos. Resolve redirects and ancestry, do not infer divergence from dates.
2. Fetch default-branch HEAD, commit date, current stable release and release notes, package channel if applicable, license/archive state, parent/source metadata. Record blocked/absent/unverified fields. Separate latest source, released package, installed pin and deeply reviewed revision.
3. Compare against last observed for triage AND last reviewed SHA for unresolved backlog. For changed sources read relevant diffs, docs, source and tests, migration/API/MCP/CLI contracts, security fixes and dependency compatibility; assess reusable capabilities even outside current target. Note range limitations, rewritten history and deferred work. No new commit does not imply no new release. For each meaningful change record exact refs/citations, what changed, affected capabilities, prior gap, benefit/risk, proposed test/metric and adopt/test/defer/no-impact/blocked with reason. Titles alone are leads. Do not advance reviewed baseline until deep review is complete.
4. Archive dated scan in registry/reviews or case and reference in UPSTREAM_REVIEW.md, CONTEXT and LEARNING_DELTA. Register new useful resources; retain negative results and old snapshots. Independent review and regression required before adoption or global default change. No automatic fork sync, dependency upgrade, installation or promotion.
5. Recheck selected tool versions before execution. If blocked use justified verified fallback or mark lane blocked. Replit separately reviewed. 
## Utility
Run `python scripts/resource_refresh.py --output report.json` using authenticated gh CLI; optionally `--previous previous.json`. Reads all catalog sources and discovered parent/source, release notes and comparison metadata; no install or writes to remote sources. Output is a triage receipt, not a completed semantic review. Inspect changed files from last reviewed SHA, including pending backlog. Profile discovery is an agent task, not automatically inferred by scanner. Review and commit report with scope.
