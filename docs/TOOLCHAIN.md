# Tool routing and synchronization
registry/tools.json is a candidate catalog, not installed integrations. Resolve upstream/fork, exact commit/release, license/redistribution, runtime, costs, permissions, maintenance and test before use. NOASSERTION/unknown licenses require review. Use relevant 1–3 candidates and fallback per feature; search owner's GitHub/Atlas and public repos, follow linked resource lists as discovery, never bulk clone or run unreviewed code.
- REA: official morluto/rea docs and installed npm release may differ from user's fork. Verify actual package version, rea doctor, rea providers, MCP tools/list and binary_session tool availability. Review setup plan before approved installation; restart agent as necessary. Browser observer is passive; use Playwright/Obscura/manual driver. Record allowed loopback CDP profile and arm observer before actions. Use actual connected schemas, not guessed arguments.
- Ghidra: conditional native provider; identify artifact format/runtime first (Electron JS/ASAR first, .NET managed first). Big_Idea audit documents >=12.2 and matching full JDK; verify live docs, host limitations and actual provider. Install separately from official release, never vendor entire binary. Use rea doctor --provider ghidra --json and rea providers --json; verify native tool availability. Windows P0 and X11 desktop capture limits apply as documented by actual release.
- Playwright/Obscura: select one driver, isolated authorized profile, no stealth/access bypass. Verify interoperability on local fixture; fallback to approved Chrome/Playwright/manual. Capture trace/screenshots, redacted HAR and step IDs. REA offline trace analysis is another supported lane when verified.
- Craft Anything: inspect its actual inputs/outputs, license and fixture before independent reconstruction. Do not assume auto-clone or compatibility.
- Treg/OmniGet/Last30Days: tool marketplace, supported public media, recent community evidence; check provider access/cost and limitations. Jev/Guard optional classifier/routing; deterministic permission gates authoritative.
- GitHub/Atlas: match exact features to code/tests, not name; use pinned versions and license cards. Distinguish software, skills, SDKs, hosted services, lists.
Adapter receipt: tool_id, source/pin, license, installed version, OS/runtime, live tools, permission, setup, fixture ID, input/output schema, PASS/FAIL/BLOCKED/NOT_RUN, log/hash, fallback, timestamp. Shared exports: run/scenario/step IDs, redacted trace/HAR/screens/schema/test receipt. Direct RPC not required; no fabricated compatibility. Promotion: CATALOGUED → SOURCE_REVIEWED → PINNED → INSTALLED → FIXTURE_PASS → TARGET_PASS. CI structural tests are not external provider verification.


## Use the smallest adequate verified toolchain
Compare direct CLI / leanrea, REA and Craft Anything on applicable, authorized ground-truth fixtures; choose by evidence coverage, time, costs, correctness and interoperability, not branding. External REA benchmark and false-negative leads appear in docs/RESOURCE_AUDIT.md. For source-known fixtures, independently compare tool output with source or expected results, especially when an analyzer reports zero. Craft Anything README describes an early-alpha clean-room workflow (not an OS sandbox), CLI/MCP and Claude-first support; inspect actual installed commands and verify Codex compatibility separately. Keep optional agent-specific mods out of the default stack unless they add demonstrated value.

Mandatory per-investigation upstream review: docs/UPSTREAM_REVIEW.md. Replit (docs/REPLIT.md) is an optional hosted development/test/deployment candidate for independent applications; validate GitHub handoff, skills, browser tests, dependencies, costs, export and data boundaries. No claim it can host REA/Ghidra without actual compatibility tests.
