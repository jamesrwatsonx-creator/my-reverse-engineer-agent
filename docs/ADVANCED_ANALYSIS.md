## Fallback
Classify acquisition vs delivery, provider/host unsupported, crash/timeout, missing or contradictory observations, access/license restriction, non-identifiability and unavailable data. Recover retained results, narrow scope, adjust documented settings, compare a verified alternate only if evidence gain justifies cost. No blind retry. Stop restricted lanes; use documented interfaces, approved fixtures and independent outcome reconstruction. Preserve residual unknowns and separate knowledge from functional acceptance. Local inference is for confidentiality, not safeguard evasion. AALpy/LearnLib on permitted fixtures and independent models, with holdouts, not private backend extraction.
